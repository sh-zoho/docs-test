# Getting Started

Welcome to the Acme documentation. This guide will help you get up and running quickly.

## Prerequisites

Before you begin, ensure you have the following:
- An Acme account
- API key from your dashboard
- Node.js 18 or higher installed

## Installation

Run the following command to install the Acme SDK:

```bash
npm install acme-sdk
```

## Your first API call

Once installed, initialise the client with your API key:

```javascript
const acme = require('acme-sdk');
const client = new acme.Client({ apiKey: 'YOUR_API_KEY' });
```

You are now ready to make your first API call.
